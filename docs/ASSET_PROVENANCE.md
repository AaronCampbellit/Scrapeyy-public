# Publication asset provenance

The extension icon is an original geometric drawing created for this publication preparation on 2026-10-08: a paper sheet, data rows and a pointer. Its editable source is [source.svg](../public/icon/source.svg); [render-icons.js](../scripts/render-icons.js) renders the five PNG sizes through Chromium. It uses no downloaded image, font, logo or template. This original artwork follows the repository's original-material terms.

The former icon rasters and three unreferenced design concept images had no documented provenance. The private repository preserves them in `docs/design/`, including the former icons in `docs/design/private-icons/`. This directory is excluded from the public repository and source ZIPs; the application uses the documented SVG artwork in both builds. This records a missing provenance record, not an accusation about the original images. Private repository history remains private and is not part of the public repository.

README screenshots are real captures of the extension against the local synthetic fixture described in [screenshots/README.md](screenshots/README.md). Captured content is project demonstration material; no customer session or third-party website is shown.
