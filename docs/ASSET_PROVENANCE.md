# Publication asset provenance

The active Scrapeyy icon from 0.1.21 depicts a physical scraper with a blue handle and pale cyan blade on a navy badge. Aaron explicitly requested a new icon used everywhere and specified a scraper design on 2026-10-22. It was generated with the built-in OpenAI image generation tool, without reference images. The [canonical master, full prompt, and resize instructions](branding/README.md) are preserved in the shared repository. All five active PNG sizes are derived from this one master; no other icon design is used by the application.

The geometric paper/data/pointer SVG from 2026-10-08 is preserved in [branding/archive/paper-icon.svg](branding/archive/paper-icon.svg), outside the runtime public directory. The original paintbrush rasters and other unreferenced concepts remain private under `docs/design/`. Those historical files are excluded from the public repository and source ZIPs. Private Git ancestry remains private.

Current popup, inbox and preview screenshots are real renders of compiled 0.1.21 pages with synthetic API fixtures. The selection screenshot is retained historical 0.1.7 evidence and contains no brand icon. See [screenshot evidence](screenshots/README.md). These images contain no customer session data.
