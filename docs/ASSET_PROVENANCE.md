# Publication asset provenance

The extension icon is an original geometric drawing created for this publication preparation on 2026-10-08: a paper sheet, data rows and a pointer. Its editable source is [source.svg](../public/icon/source.svg); [render-icons.js](../scripts/render-icons.js) renders the five PNG sizes through Chromium. It uses no downloaded image, font, logo or template. This original artwork follows the repository's original-material terms.

The former icon rasters and three unreferenced design concept images had no documented provenance. They were replaced or removed from this candidate tree. This records a missing provenance record, not an accusation about the original images. The old private repository history remains private and is not part of the fresh publication candidate.
