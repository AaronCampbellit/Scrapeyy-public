# Publication asset provenance

The active extension icons are the original Scrapeyy paintbrush/document PNGs, restored at Aaron's explicit request in 0.1.19. All five sizes are byte-for-byte copies of the icons used before the public/private source merge. The project has no additional provenance record for those original rasters; restoring them does not create a new authorship or licensing claim.

The geometric paper/data/pointer design created for publication preparation on 2026-10-08 remains available as the alternate [source.svg](../public/icon/source.svg). Its [renderer](../scripts/render-icons.js) writes previews only under `work/alternate-icons/`; it does not overwrite the active icons. That alternate drawing uses no downloaded image, font, logo, or template and follows the repository's original-material terms.

The private repository also preserves the original rasters in `docs/design/private-icons/` and the three unreferenced concept images in `docs/design/`. This directory remains excluded from the public repository and source ZIPs. Private repository history remains private and is not part of the public repository.

README screenshots are real captures of the extension against the local synthetic fixture described in [screenshots/README.md](screenshots/README.md). Captured content is project demonstration material; no customer session or third-party website is shown.
